GAT150 Final Project

Project Overview

This project was developed as the final project for GAT150. It is a
2D pixel-art platforming game that focuses on player movement,
environmental navigation, obstacles, and basic gameplay systems.

The game presents the player with a side-scrolling style environment
made from pixel-art assets. The player character must navigate a series
of grass-covered platforms while avoiding hazards and interacting with
the level environment.

The current game scene includes:

A three-life system

A simple platforming environment

Game Systems

Player

The player character is able to navigate the level by moving across
platforms and jumping between different areas of the environment.

Score

A score counter is displayed in the upper-left corner of the screen. The
system is intended to track the player's progress during gameplay.

Lives

The game includes a three-life system, displayed in the upper-right
corner. Losing a life represents a gameplay failure and gives the player
additional attempts to complete the level.

Enemies

An enemy bat is present in the level and acts as a hazard for the
player. Enemy placement adds an additional challenge to platform
navigation.

Level Design

The level uses multiple elevated platforms, gaps, and environmental
objects to create a simple platforming challenge. Wooden crates and
different platform heights help add variety to the environment.

Art Style

The project uses a pixel-art visual style. Characters, enemies,
platforms, and environmental objects are designed with pixel-based
artwork to create a cohesive retro-inspired appearance.

The level uses a limited color palette with blue-gray backgrounds, green
grass platforms, brown wooden crates, and colorful character sprites.

Project Goals

The primary goals of this final project were to:

Develop a functional 2D platforming experience.

Implement basic player movement and jumping.

Create a playable level using environmental and platform elements.

Incorporate gameplay systems such as scoring and player lives.

Use pixel-art assets to establish a consistent visual style.

Demonstrate concepts and skills developed throughout GAT150.

Development

This project represents the application of skills learned throughout the
GAT150 course. The final product combines level design, gameplay
mechanics, visual assets, and user-interface elements into a single
playable experience.
